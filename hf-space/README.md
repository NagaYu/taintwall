# TaintWall Demo

This page is a precomputed deterministic demo; there is no server-side execution. It shows the existing `scripts/demo_runbook.py` scenario and its C0/C3 outcomes. The page uses no LLM, external assets, external fonts, analytics, or API keys.

The procedure result table contains PREVIEW measurements for `qwen2.5:14b` on a deterministic 16-case sample with one trial. These results are limited to the measured model and cases; see the Phase 2 final report for details.

The dataset package and GitHub repository links are shown on the page. The GitHub URL remains a placeholder until the public repository is finalized.
